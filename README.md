- Inicio de sesión y registro de usuarios
- Reservas de mesas con disponibilidad en tiempo real
- Menú digital con filtro por categorías
- Comandas digitales con estados
- Facturación con cálculo de IVA
- Horarios de atención con indicador de abierto/cerrado
- Diseño responsivo (móvil, tablet, escritorio)
